# Vaibhav Foundation Welfare Society

Next.js website for Vaibhav Foundation Welfare Society, rebuilt from the existing site content and structure at [vaibhavfoundation.com](https://vaibhavfoundation.com).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — run ESLint

## Pages

Home, About, Contact, Donate Now, Education, Healthcare, Women Empowerment, Volunteer, Become Volunteer, Media Centre/News, and legal policy pages.
